# Slides e listas simples

Exercício de front-end para praticar HTML, CSS e JavaScript por meio de uma interface de produtos, favoritos e área de slides.

## Tecnologias

- HTML5
- CSS3
- JavaScript no próprio arquivo HTML

## O que este exercício explora

- Formulário para nome, descrição e URL de imagem
- Representação de produtos em um array de objetos
- Criação dinâmica de elementos com JavaScript
- Estrutura visual para listagem e favoritos

## Como visualizar

```bash
git clone https://github.com/mylennacavalcante/Slides-e-listas-simples.git
cd Slides-e-listas-simples
```

Abra `index.html` no navegador. Não há instalação de dependências ou etapa de compilação. As imagens externas precisam de conexão com a internet.

## Estado do exercício

Em desenvolvimento. A estrutura visual está presente, mas a navegação dos slides e a alternância de favoritos ainda não estão concluídas. A renderização de novos produtos também precisa de ajustes. Os dados ficam apenas em memória, sem persistência.

## Arquivos

- `index.html`: marcação, formulário e lógica inicial
- `style.css`: estilos da página
